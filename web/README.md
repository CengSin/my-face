# 今天的天气

个人心情站。每天一条心情，用天气说。首页的 3D 小岛与当天文章心情同步，后台可以写 Markdown、存草稿和发布文章。

现在也支持 **Cloudflare Workers + D1**。Cloudflare 部署、随机后台口令、文章迁移和本地验证步骤见 [CLOUDFLARE.md](CLOUDFLARE.md)。下面的 Node/SQLite 使用方式继续保留；两种环境的数据独立。

## 启动与第一次写作

需要 **Node.js 24+**，数据库使用 Node 内置 SQLite，不需要另外安装数据库。

```bash
npm install
# 终端一：启动文章服务（默认 4301 端口）
npm run server
# 终端二：启动页面
npm run dev
```

1. 打开 Vite 输出的本机地址，点击右上角「写作室」，或访问 `/admin`。
2. 第一次使用设置一个 12–128 字符的后台密码；之后使用此密码登录。没有内置正式账号或默认密码。
3. 填写标题、日期、心情和 Markdown 正文。可在「写作 / 对照 / 预览」之间切换；开始编辑后「我的文章」会自动折叠，可随时从左侧窄栏展开。
4. 点击格式栏的「图片」选择 JPEG、PNG、GIF 或 WebP（单张不超过 1.5 MB），或直接把剪贴板图片粘贴到 Markdown 编辑区；成功后会自动在光标处插入并立即显示预览。
5. 「保存草稿」仅你可见；「发布文章」后，该日期的首页列表会出现文章，点击可阅读全文。
6. 已发布文章可修改更新或转回草稿；更新时会检查版本，避免覆盖另一个标签页刚保存的修改。

草稿保存到服务器，而不是浏览器缓存。正文编辑是手动保存，未保存时有状态提示与离开提醒；保存失败或登录过期时保留当前输入。刷新前请先保存。

## 日期与心情规则

- 每篇文章选择一个日期和一种天气心情。
- **同一天多篇文章，以最近更新的已发布文章心情决定首页天气**；草稿不改变公开天气。
- 首页按日期展示当天所有已发布文章，多篇时列表可滚动；有新日期时自动加入日期导航。
- 今天没有文章时显示「待记录」，不伪造作者心情。原来的四条展示内容保留。
- 发布立即生效；选择未来日期不代表定时发布。
- 阅读链接为 `/articles/文章ID`，返回当天链接为 `/?date=YYYY-MM-DD`。

## 数据、权限与备份

默认数据位于 `web/data/journal.sqlite`，已加入忽略规则；内容包括文章、密码的加盐 scrypt 哈希和会话摘要，不保存明文密码。可用 `JOURNAL_DB` 指定其他持久化路径。

服务只监听本机 `127.0.0.1`。后台接口要求登录；会话有效期 12 小时，使用 HttpOnly / SameSite=Strict Cookie，退出会使会话失效。写请求检查 Origin 与专用请求头，登录失败有频率限制。Markdown 不执行原始 HTML，危险链接会被过滤；HTTP(S) 图片仍会向图片主机发出请求。

首次密码设置仅开放于本机开发模式，生产模式禁止首次注册。不要将未配置的开发服务暴露到公网。

文章图片与正文保存在同一数据库中，备份时先停止文章服务，再复制整个 `data` 目录（包含 SQLite/WAL 相关文件）。恢复前也应停止服务。该版本尚未提供找回密码、多人账号、图片管理/删除或定时发布。

## 构建后运行

`npm run build` 后可直接运行 `npm start`，通过 `http://127.0.0.1:4301` 使用同一服务提供页面和 API。

将来部署需先完成本机密码初始化，使用持久化磁盘存放数据库，并配置 HTTPS 反向代理。生产环境设置 `NODE_ENV=production`、`PUBLIC_ORIGIN=https://你的实际域名`，可选 `API_PORT` 和 `JOURNAL_DB`。代理应保留原始 Host，页面与 API 必须同源；生产 Cookie 强制 Secure。当前没有部署到公网。

## 浏览方式

- 向下滚动，回看前几天；也可以点击底部日期卡或翻页箭头。
- 在心情小岛上按住鼠标左右拖动即可旋转；松手会自然减速，触屏设备也支持横向拖动。
- 点击站名回到最近一条记录；保留 `#1`、`#2` 等原有序号深链接。
- “关于这里”说明网站概念，支持 Esc 关闭并恢复焦点。
- 可暂停天气动效；跟随系统“减少动态效果”，暂停烟雾、云层和雨滴。后台标签页停止渲染。
- 3D 初始化失败时显示回退文案，心情内容与导航仍可使用。

## 内容和验证

`src/moods.ts` 仅保留最初的示例心情；实际文章在后台维护。星期从日期自动计算。

```bash
npm run build
npm run lint
npm test
```

16 项测试覆盖小岛拖动映射、释放速度与惯性衰减，以及原有滚动/日期逻辑、每日天气归并、Markdown 与图片安全、认证、草稿隔离、图片上传、发布/撤回、并发版本、输入校验、登录限流和重启持久化。测试会启动隔离的本机服务器并使用临时数据库，不接触正式数据。

可选 UI 验收：先构建，再运行 `node server/test-preview.mjs`。它只使用内存数据库，在 `http://localhost:4302` 提供独立测试页面；测试密码见该脚本，不能登录正式后台。停止进程即丢弃测试数据。

后台、阅读器、Markdown 和 3D 分块加载；Three.js 模块仍有默认 500 kB 提示，不影响构建。

本地预览不等于公开发布。Cloudflare 版已在服务端生成绝对地址的 `og:image` / `twitter:image`；正式部署后仍需实际检查公网页面和封面响应。原有 Node 版发布时需自行配置元数据的绝对域名。

# Markdown 写作后台验收 · 2026-08-30

## 功能范围

- `/admin`：本机首次密码设置、登录/退出、文章列表、搜索/状态筛选。
- 标题、日期、四种心情、Markdown 写作/对照/预览与格式快捷按钮。
- 手动保存草稿、发布、编辑已发布文章、转回草稿；未保存离开提示。
- 文章写入服务器 SQLite；HttpOnly 会话、登录限流、Origin 校验和版本冲突保护。
- 首页当前日期文章列表；点击进入 Markdown 阅读页，返回对应日期。
- 同日多篇文章的首页天气取最近更新的已发布文章，草稿不影响公开数据。

## 自动验证

12 项测试通过：原有日期/滚动逻辑、按日天气归并、Markdown GFM 与脚本过滤、完整登录/草稿/发布/撤回流程、非法输入、越权访问、伪造来源与 Host、并发设置保护、版本冲突、重启后的内容持久化、生产模式禁用首次设置及登录限流。

`npm run build` 和 `npm run lint` 通过。Three.js 独立模块仍有原来的体积提示，不阻塞构建。

## 浏览器验收

使用 `server/test-preview.mjs` 提供的独立内存数据库，不向正式库写入测试文章或密码。

- 桌面：登录、Markdown 输入与实时预览、选择多云、保存草稿、未保存切换提醒与继续写作、发布成功、首页天气/文章同步、阅读全文。
- 390px 手机：后台无横向溢出，成功发布同日第二篇文章；阅读页正常展示标题、加粗、引用、任务列表、表格与代码块。
- 正式后台保持待首次设置状态；正式文章列表为空。

## 使用边界

- 需要 Node 24+；开发时分别启动 `npm run server` 和 `npm run dev`。
- 本轮仅本机交付，未公开部署；部署前需持久化磁盘、HTTPS 与生产配置。
- 不含多人账号、找回密码、附件上传、自动保存和定时发布。
- 备份需停止服务后复制整个 `web/data` 目录；不要提交数据库或密码信息。
- 截图若包含文章文字，均为隔离验收的示例数据，不是作者真实文章。
